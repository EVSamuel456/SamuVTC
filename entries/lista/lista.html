Como hacer una lista de entradas de blog (fácil)

5/9/2026

Paso 1: Crear un archivo .json

Crear el archivo en la carpeta raíz de tu proyecto HTML, y recuerda ponerle un nombre que recuerdes fácil (ejemplos: posts, entradas, entre otras...). Una vez creada, debes agregar una estructura de lo que se mostrará en la entrada. Aquí un ejemplo:

                    
[
    {
        "título": "Nombre de la entrada",
        "fecha": "3/9/2026",
        "descripción": "una descripción de tu entrada",
        "imagen": "imagenes/imagen.jpg",
        "url": "entradas/entrada.html"
    }
]

Pueden ser los nombres que quieras. Recuerda que en imagen y url deben tener la dirección de su respectiva imagen y archivo de entrada.

Paso 2: Has la etiqueta de la lista en el HTML

Dentro del "body" del HTML principal agrega un div donde se creará la lista de entradas y luego colocale el "id" y "class" que quieras.

                    
<div class="entries-list" id="entries-list">

El "class" es para cuando quieras editar el estilo de la lista, y el "id" para que el siguiente script pueda identificar a esta.

Paso 3: Crear script JavaScript corto

Con el archivo .json en la carpeta, crea otro archivo de extensión .js y ponle el nombre que quieras (ejemplos: script, blog...). Dentro de este deberas poner un código similar a este:

                    
fetch('posts.json') // nombre del archivo .json.
    .then(response => response.json())
    .then(entradas => {
        const contenedor = document.getElementById('entries-list'); // nombre del id del HTML.
        
        entradas.forEach(entrada => {
            const elemento = document.createElement('li');
            elemento.className = 'entry'; // "class" de la entrada.
            elemento.innerHTML = `
                <a href="${entrada.url}">
                    <h1>${entrada.título}</h1>
                    <small>${entrada.fecha}</small>
                    <img src="${entrada.imagen}">
                    <p>${entrada.descrición}</p>
                </a>
            `;
            contenedor.appendChild(elemento);
        });
    })
    .catch(error => console.error('Error al cargar las entradas:', error));

Paso 4: Agrega el archivo JavaScript

Agrégalo al "body" de tu HTML, y Para más comodidad, colocalo debajo de "entries-list"

                    
<div class="entries-list" id="entries-list"></div>
<script src="blog.js"></script>
<!--agregalo aquí-->

Paso extra: Dale estilo con CSS

Si sabes usar, agrégale un diseño para que tenga más estilo. Aquí un ejemplo:

                    
.entries-list {
     background-color: White;
     max-width: 60%;
}

.entry {
   display: block;
}

¿Cómo se usa?

Al subir una nueva entrada a tu carpeta de entradas, debes registrarla en la fila de tu .json. Esto hará que JavaScript la coloque automáticamente en la lista de entradas. Ejemplo:

                    
[
    {
        "título": "Entrada 2",
        "fecha": "5/9/2026",
        "descripción": "una descripción de tu entrada",
        "imagen": "imagenes/imagen.jpg",
        "url": "entradas/entrada.html"
    },
    {
        "título": "Entrada 1",
        "fecha": "3/9/2026",
        "descripción": "una descripción de tu entrada",
        "imagen": "imagenes/imagen.jpg",
        "url": "entradas/entrada.html"
    }
]
